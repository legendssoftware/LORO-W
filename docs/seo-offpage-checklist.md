# LORO SEO — off-page checklist

Complete after production deploy with `NEXT_PUBLIC_SITE_URL` set.

## Search consoles

1. [Google Search Console](https://search.google.com/search-console) — add property, set `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` in Vercel/host env
2. [Bing Webmaster Tools](https://www.bing.com/webmasters) — set `NEXT_PUBLIC_BING_SITE_VERIFICATION`
3. Submit `https://<your-domain>/sitemap.xml`

## Directories (field sales category)

- G2 — Field Sales Management
- Capterra — Field Sales / Mobile CRM
- GetApp — equivalent categories

Use consistent description: field sales software for South Africa, visits, routes, pipeline, ERP.

## PR & comparisons

- Publish case studies on `/customers` when approved
- Monitor branded queries: `loro field sales`, `loro vs skynamo`
